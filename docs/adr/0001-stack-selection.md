# Выбор технологического стека: Laravel 11/12, Vue 3 Composition API, PostgreSQL в Docker

Для корпоративного финансового дашборда выбран стек на базе PHP/Laravel для бэкенда, Vue 3 Composition API с Tailwind CSS и Chart.js для пользовательского интерфейса, и PostgreSQL в контейнере Docker Compose.

## Контекст и решение
Требуется надежный корпоративный бэкенд с реляционной базой данных (PostgreSQL), развитой системой миграций, сидов и валидации данных, а также реактивный интерактивный интерфейс для работы с графиками и динамическими фильтрами. Было принято решение:
1. Использовать **Laravel** в качестве REST API бэкенда (миграции, модели Eloquent, валидация запросов, контроллеры импорта/экспорта CSV).
2. Использовать **Vue 3 Composition API** + **Tailwind CSS** + **Chart.js** + **jsPDF** на фронтенде (сборка через Vite или одностраничное SPA-приложение, интегрированное с Laravel).
3. Использовать **PostgreSQL** в `docker-compose.yml` с постоянным хранилищем томов (volume).
