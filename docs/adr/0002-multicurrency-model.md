# Модель мультивалютности и пересчета курсов

В системе финансового дашборда требуется поддержка нескольких валют (RUB, USD, EUR, CNY, KZT) с динамическим пересчетом всех агрегатов, KPI и графиков.

## Контекст и решение
Принято решение:
1. Все базовые финансовые операции (транзакции) сохраняются в базе данных в основной базовой валюте учета компании (рубли, RUB) с указанием точной суммы и даты.
2. В интерфейсе и API предоставляется таблица актуальных курсов валют (с возможностью кастомизации или настройки в интерфейсе/конфигурации).
3. При переключении валюты в верхней панели все показатели (KPI выручки, расходов, чистой прибыли, графики динамики и структуры) мгновенно пересчитываются по выбранному курсу.
