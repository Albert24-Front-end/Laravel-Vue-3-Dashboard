# Серверная генерация PDF-отчетов в Laravel

Для формирования официальных корпоративных PDF-отчетов используется серверный рендеринг через Laravel с библиотекой `barryvdh/laravel-dompdf` (на базе dompdf).

## Контекст и решение
Финансовые отчеты компании требуют строгого типографического оформления, поддержки печати на листах формата A4, корректного отображения таблиц, колонтитулов и сводных данных независимо от браузера клиента.
1. Бэкенд на Laravel предоставляет эндпоинт `GET /api/reports/pdf?year=...&month=...&currency=...`.
2. Сервер собирает актуальные агрегированные показатели, структуру расходов и список операций за выбранный период и компилирует брендированный Blade-шаблон в бинарный поток PDF (`application/pdf`).
3. На клиенте кнопка «Экспорт в PDF» скачивает сформированный файл отчета.
