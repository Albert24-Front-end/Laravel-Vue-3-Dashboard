# Интеграция с API курсов валют (ЦБ РФ)

Для обеспечения динамического пересчета показателей в выбранную валюту (USD, EUR, CNY, KZT) реализована интеграция с официальным API Центрального банка РФ.

## Контекст и решение
1. Бэкенд запрашивает актуальные котировки валют с сервиса ЦБ РФ (`https://www.cbr-xml-daily.ru/daily_json.js`) с кэшированием результатов на 12-24 часа во избежание избыточных внешних запросов.
2. В случае недоступности внешней сети бэкенд использует безопасные дефолтные значения курсов, предотвращая сбои в работе интерфейса.
3. Эндпоинт `GET /api/currencies` возвращает словарь валют, их символы и текущие курсы пересчета относительно базового рубля (RUB).
