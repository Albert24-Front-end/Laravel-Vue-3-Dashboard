# Модульная компонентная архитектура Vue 3 SPA и отказ от монолитного интерфейса

Пользовательский интерфейс переведен на чистый компонентный подход Vue 3 Composition API с полным разделением обязанностей.

## Контекст и решение
1. Монолитный файл интерфейса заменен на модульную структуру компонентов:
   - `TheHeader.vue` / `TheFooter.vue` — глобальный каркас и панель управления.
   - `AuthModal.vue` — модальное окно авторизации и регистрации.
   - `KpiCardsGrid.vue` и `KpiCard.vue` — карточки KPI с форматированием разрядов через пробелы.
   - `ChartsSection.vue`, `MonthlyComparisonChart.vue`, `ExpenseStructureChart.vue` — интерактивные графики Chart.js.
   - `OperationsSection.vue`, `TransactionForm.vue`, `TransactionTable.vue`, `CsvImportModal.vue` — форма, таблица операций и импорт CSV.
2. Состояние и логика инкапсулированы в переиспользуемые composables:
   - `useAuth.js` — аутентификация, токен, профиль пользователя.
   - `useCurrency.js` — курсы валют, конвертация и форматирование сумм.
   - `useDashboard.js` — состояние аналитики и фильтры периода.
   - `useTransactions.js` — работа с реестром операций.
   - `useToast.js` — глобальные уведомления.
3. Сетевое взаимодействие организовано через изолированный клиент `api/client.js` с автоматической подстановкой Bearer-токена и перехватом 401 ошибок.
